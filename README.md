# Discord AI Moderation Bot

Небольшой Discord-бот для модерации русскоязычных сообщений. Локальная TF-IDF/Ridge-модель оценивает токсичность по шкале 1–10. Бот считает предупреждения, удаляет сообщения с высоким баллом, может выдать timeout и отправляет отчёты модераторам.

## Быстрый запуск

1. Установите Python 3.12+ и создайте бота в [Discord Developer Portal](https://discord.com/developers/applications). Включите **Message Content Intent**, пригласите бота с разрешениями читать сообщения, управлять сообщениями, отправлять сообщения и применять timeout.
2. В папке проекта выполните:

   ```powershell
   py -3.12 -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -e .
   Copy-Item .env.example .env
   ```

3. Добавьте токен и, при желании, ID сервера и канала модерации в `.env`.
4. Можно сразу запустить бота с включённой моделью. Если захотите дообучить её на своих разрешённых примерах, сначала выполните шаги в разделе «Модель», затем запустите:

   ```powershell
   python -m discord_moderation_bot
   ```

## Модель

В `models/toxicity_model.joblib` лежит компактный экспорт модели из исходного проекта: сырые тексты обратной связи удалены из файла, оставлены веса и векторизатор. Модель всё ещё обучена на этих примерах; проверьте допустимость публичного распространения весов. Подробности — в [MODEL_CARD.md](MODEL_CARD.md). Для обучения собственной модели:

1. Скопируйте `data/training.example.csv` в `data/training.csv`.
2. Добавьте свои примеры с колонками `text,score` (оценка от 1 до 10); для первого запуска нужно не менее 20 строк. Используйте тексты, которые разрешено обрабатывать и хранить.
3. Установите зависимости и выполните `python -m training.train_model`. Модель появится в `models/toxicity_model.joblib`.

Модель — baseline для демонстрационного проекта, а не универсальный классификатор. Перед реальным сервером проверьте её на собственных примерах и настройте пороги в `.env`. `joblib` использует pickle и версия scikit-learn зафиксирована, чтобы снизить риск несовместимой загрузки.

## Design decisions

- Discord API и sklearn-вычисления разделены; предсказание запускается через `asyncio.to_thread`, чтобы не блокировать обработку событий.
- Настройки и секреты читаются из `.env`; токен, ID и данные сервера не зашиты в код.
- Для счётчика предупреждений используется SQLite из стандартной библиотеки: там хранятся только ID сервера/пользователя и счётчик. Текст сообщения включается в embed отчёта для модераторов, но не сохраняется в SQLite.
- Порог предупреждения и тяжёлого нарушения настраиваются отдельно. Повторные нарушения приводят к timeout; тяжёлое сообщение удаляется и сразу получает отдельный timeout. Неуспех действия попадает в лог.
- `joblib`-модели сериализованы через pickle: загружайте только собственные или доверенные файлы.

## Переменные окружения

| Переменная | Назначение | Значение по умолчанию |
|---|---|---|
| `DISCORD_BOT_TOKEN` | Токен Discord-бота | обязательно |
| `DISCORD_GUILD_ID` | Ограничение одним сервером | пусто |
| `MODERATION_CHANNEL_ID` | Канал отчётов модерации | канал исходного сообщения |
| `MODEL_PATH` | Путь к обученной модели | `models/toxicity_model.joblib` |
| `DATA_PATH` | SQLite-файл предупреждений | `data/moderation.sqlite3` |
| `TRAINING_DATA_PATH` | CSV для повторного обучения | `data/training.csv` |
| `MODEL_OUTPUT_PATH` | Куда сохранять обученную модель | `models/toxicity_model.joblib` |
| `WARNING_THRESHOLD` | Балл для предупреждения | `6` |
| `SEVERE_THRESHOLD` | Балл для удаления и timeout | `10` |
| `WARNINGS_BEFORE_TIMEOUT` | Предупреждений до timeout | `3` |
| `WARNING_TIMEOUT_MINUTES` | Timeout после серии предупреждений | `60` |
| `SEVERE_TIMEOUT_MINUTES` | Timeout за тяжёлое нарушение | `180` |
| `LOG_LEVEL` | Уровень логирования | `INFO` |

## Права и ограничения

Для модерации нужны **Message Content Intent** в настройках приложения и `message_content` intent в коде. Роль бота должна стоять выше ролей пользователей, которых он модерирует. На обычных сообщениях ниже порога бот не отвечает. Автоматическая оценка может ошибаться — оставляйте модераторам возможность пересмотреть решения.
